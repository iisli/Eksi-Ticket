# Eksi-Ticket

> Демонстрационное приложение с интерфейсом электронного билета для Николаевэлектротранса.

## О проекте

**Eksi-Ticket** — Экспериментальный проект

Приложение имитирует внешний вид электронного билета и предназначено исключительно для демонстрационных и тестовых целей.

Eksi-Ticket не является официальным приложением Николаевэлектротранса и не связано с его официальными системами.

## Важно

**Eksi-Ticket не является настоящим билетом и не подтверждает оплату проезда.**

Проект предназначен исключительно для разработки, тестирования и демонстрации интерфейса.

Не используйте приложение в качестве замены настоящему билету или официальному подтверждению оплаты.

Автор не несёт ответственности за использование проекта не по назначению и за любые последствия такого использования.

## Цель проекта

Основная цель проекта — экспериментирование с дизайном и интерфейсом электронного билета, а также изучение реализации подобных пользовательских интерфейсов.

Проект не предназначен для взаимодействия с реальными билетными или платёжными системами.

## Статус

**Experimental / Demo**

Проект находится в разработке. Функциональность и внешний вид могут изменяться.

## Лицензия

Проект распространяется в ознакомительных и экспериментальных целях.

Использование проекта осуществляется на собственный риск пользователя.
